# EduGenie: Google Gemini Powered Learning Assistant

EduGenie is an interactive AI-powered learning assistant built with Streamlit and Google Gemini 1.5 Flash API.

## Features
- **Concept Explainer:** Tailors academic explanations according to student difficulty levels.
- **Quiz Generator:** Automatically creates multiple-choice practice quizzes with solutions.
- **Homework Helper:** Delivers step-by-step guidance for code debugging, math problems, and theoretical queries.

## Tech Stack
- **Frontend / UI:** Streamlit
- **AI Model:** Google Gemini API (`gemini-1.5-flash`)
- **Language:** Python

## How to Run Locally
1. Clone the repository: `git clone `
2. Install dependencies: `pip install -r requirements.txt`
3. Run Streamlit: `streamlit run app.py`
